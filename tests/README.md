# Documentação de Testes — Cidade Ativa

Esta pasta contém os documentos utilizados para planejar, executar e registrar os testes do projeto.

## Arquivos

- `Plano_de_Testes_Cidade_Ativa.docx`: planejamento e escopo dos testes.
- `Casos_de_Teste_Cidade_Ativa.docx`: casos de teste e resultados esperados.
- `roteiro-de-testes.md`: instruções para execução dos testes.

## Orientações

Consulte o plano de testes antes de iniciar a execução. Utilize os casos de teste para validar as funcionalidades e siga o roteiro para registrar os resultados.

As falhas encontradas devem ser documentadas com informações suficientes para permitir sua reprodução e correção.
